# 🩺 Health Risk Predictor

A machine learning web app that predicts health risks (0 = Low, 1 = High) based on patient data like age, weight, blood pressure, cholesterol, and glucose levels.

## 📌 Features
- Preprocessing pipeline using `scikit-learn`
- Random Forest model with hyperparameter tuning (`GridSearchCV`)
- Model saved using `joblib`
- Interactive Streamlit app for predictions
